The **NX584** {% term integration %} provides integration with GE, Caddx, Interlogix (and other brands) alarm panels that support the NX584 interface module (or have it built in). Supported panels include NX4/6/8/8E. Actual integration is done through [pynx584](https://github.com/kk7ds/pynx584) which is required for this to work.

## Supported functionality

The integration creates one device for the alarm panel. The alarm control panel and the zone binary sensors are always created together and belong to this device. You can disable the entities you don't need.

### Alarm control panel

The alarm panel entity shows whether the panel is disarmed, armed home, armed away, or triggered, and lets you arm and disarm it.

### Binary sensors

Each zone is exposed as a binary sensor, named after the zone name reported by the panel. This gives you visibility in the UI and lets you trigger automations instantly when something happens, like a door opening or a motion sensor triggering. Each zone sensor has the `zone_number` and `bypassed` attributes.
